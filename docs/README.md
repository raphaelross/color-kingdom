# Documentation Overview

This directory contains the current working documentation for Color Kingdom.

## What Exists Today
- App shell with `MaterialApp.router`
- Centralized `go_router` navigation
- Kid-friendly theme system
- Home screen with reusable category cards
- First coloring-engine baseline with a sample Happy Cat page
- Riverpod-based coloring state management

- Read the roadmap first to understand what is complete and what remains for MVP.
- Read the architecture document before changing cross-cutting app structure.
- Read the feature spec before extending the coloring engine.
- Read the ADRs before making technology or rendering decisions that affect the app foundation.
